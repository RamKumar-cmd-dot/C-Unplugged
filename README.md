C-Unplugged — Music Application (CLI Based)

C-Unplugged is a simple command-line music application written in C.
It lets the user manage songs, albums and playlists using linked lists.
All operations are done using a menu-driven interface where the user chooses commands by entering the command index.

The program loads all songs and albums from files at the start, allows the user to modify them, and saves the updated albums back into albums.txt when exiting.

It also keeps a command history in a file called commands.log.
